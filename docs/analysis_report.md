## 2. Выявленные пробелы

### 2.1 Темы с плохим покрытием

После запуска оценки будут выявлены следующие категории пробелов:

1. **Missing Content** — темы, отсутствующие в базе знаний
2. **Poor Chunking** — информация есть, но не находится при поиске
3. **Generation Failures** — контекст найден, но ответ некорректный

### 2.2 Искусственные пробелы (для тестирования)

В golden_questions.json определены 3 искусственных пробела:
- **VoidCore** — несуществующая планетная система
- **Xarn Velgor** — несуществующий персонаж
- **Synth Flux** — несуществующая технология

## 3. Рекомендации по улучшению

### 3.1 Расширение базы знаний

| Приоритет | Тема | Действие |
|-----------|------|----------|
| Высокий | Недокументированные API | Добавить техническую документацию |
| Средний | FAQ для новых сотрудников | Расширить onboarding материалы |
| Низкий | Исторические решения | Добавить ADR для ключевых решений |

### 3.2 Оптимизация RAG-pipeline

1. **Chunking Strategy**
   - Текущий размер чанка: 512 токенов
   - Рекомендация: Эксперименты с семантическим чанкингом

2. **Retrieval Parameters**
   - top_k_retrieval: 50
   - top_k_rerank: 5
   - Рекомендация: A/B тестирование параметров

3. **Prompting**
   - Улучшить few-shot примеры
   - Добавить примеры корректных отказов

## 5. Приложения

### 5.1 Файлы результатов

- `logs/query_logs.jsonl` — детальные логи запросов
- `logs/evaluation_logs.jsonl` — результаты оценки каждого вопроса
- `logs/evaluation_report.json` — итоговый JSON-отчёт с метриками

### 5.2 Команды

```bash
# Запуск оценки
make evaluate

# Просмотр отчёта
cat logs/evaluation_report.json | python -m json.tool

# Просмотр первых 5 логов
head -5 logs/evaluation_logs.jsonl
```
